# Chart Bot

A zero-cost, ultra-premium Agentic AI running standard ReAct reasoning loops from scratch.

## Features
- **ReAct Reasoning Loop**: Shows intermediate thoughts, tool actions, and observations in real-time.
- **Dynamic Charts**: Renders line, bar, and area charts using Streamlit widgets based on structured outputs from the LLM.
- **Connected Tools**:
  - Calculator: Safely evaluates math expressions.
  - Time Sync: Real-time clock syncing.
  - Wikipedia: Pulls data from Wikipedia.
  - Weather: Simulates live weather.
